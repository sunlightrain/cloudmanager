# 架构设计

## 系统架构

### 整体架构

```
┌─────────────────────────────────────────────────────────────────┐
│                         客户端 (Browser)                         │

                             ▼
┌─────────────────────────────────────────────────────────────────┐
│                      后端服务 (FastAPI)                          │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐            │
│  │  API Layer  │  │  Auth       │  │  Task       │            │
│  │  (Routes)   │  │  (Session)  │  │  Queue      │            │
│  └──────┬──────┘  └──────┬──────┘  └──────┬──────┘            │
│         │                │                │                     │
│  ┌──────▼────────────────▼────────────────▼──────┐            │
│  │              Service Layer (业务逻辑)           │            │
│  │  ┌──────────┐ ┌──────────┐ ┌──────────┐       │            │
│  │  │ VM       │ │ Task     │ │ User     │       │            │
│  │  │ Service  │ │ Service  │ │ Service  │       │            │
│  │  └────┬─────┘ └────┬─────┘ └────┬─────┘       │            │
│  └───────┼────────────┼────────────┼─────────────┘            │
│          │            │            │                           │
└──────────┼────────────┼────────────┼───────────────────────────┘
           │            │            │
           ▼            ▼            ▼
┌─────────────────────────────────────────────────────────────────┐
│                      数据层                                      │
│  ┌──────────────────┐  ┌──────────────────┐                  │
│  │  SQLite Database │  │  pyvmomi SDK      │                  │
```

### 分层架构

| 层级 | 职责 | 组件 |
|-----|-----|-----|
| API Layer | HTTP请求处理、参数校验 | FastAPI Router |
| Service Layer | 业务逻辑处理 | VMService, TaskService, UserService |
| Data Access Layer | 数据持久化 | SQLModel, pyvmomi |
| Infrastructure | 基础设施 | SQLite, vCenter |

## 核心模块设计

### 1. 认证模块 (Authentication)

```
┌──────────────────┐
│   Login Page    │
└────────┬─────────┘
         │ POST /api/auth/login
         ▼
┌──────────────────┐     ┌──────────────────┐
│  Auth Service   │────▶│   SQLite DB     │
│  (Session)      │     │  (User Store)   │
└────────┬─────────┘     └──────────────────┘
         │
         │ Set-Cookie: session_id
         ▼
┌──────────────────┐
│  Protected API  │
└──────────────────┘
```

**设计要点**:
- 使用SQLite存储用户信息
- Session存储在服务端，使用安全的cookie传递
- 支持密码哈希存储

```
│         │                │                │                 │
│         └────────────────┼────────────────┘                 │
│                          ▼                                    │
│               ┌─────────────────────┐                        │
│               │   vCenter Connection │                       │
│               │     (pyvmomi)        │                       │
│               └──────────┬────────────┘                        │
│                          │                                     │
│         ┌────────────────┼────────────────┐                   │
│         ▼                ▼                ▼                   │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐           │
│  │ VM Create   │  │ VM Delete   │  │ VM Reconfig │           │
```

### 3. 任务模块 (Task Management)

```
┌──────────────┐      ┌──────────────┐      ┌──────────────┐
│  User        │      │  Task        │      │  Background  │
│  Request     │─────▶│  Queue       │─────▶│  Worker      │
└──────────────┘      └──────────────┘      └──────┬───────┘
     │                      │                       │
     │              ┌──────▼───────┐                │
     │              │  Task Store  │                │
     │              │   (SQLite)   │                │
     │              └──────────────┘                │
     │                                                  │
     │  Polling / WebSocket                           │
     ◀─────────────────────────────────────────────────┘
```

**设计要点**:
- 长时间操作使用后台任务
- 任务状态存储在SQLite
- 支持任务状态查询

## 数据模型

### 用户表 (users)

| 字段 | 类型 | 说明 |
|-----|-----|-----|
| id | Integer | 主键 |
| username | String | 用户名 (唯一) |
| password_hash | String | 密码哈希 |
| email | String | 邮箱 |
| is_active | Boolean | 是否激活 |
| created_at | DateTime | 创建时间 |

### 任务表 (tasks)

| 字段 | 类型 | 说明 |
|-----|-----|-----|
| id | Integer | 主键 |
| task_id | String | UUID任务ID |
| task_type | String | 任务类型 |
| status | String | pending/running/completed/failed |
| result | Text | 结果JSON |
| error | Text | 错误信息 |
| created_at | DateTime | 创建时间 |
| completed_at | DateTime | 完成时间 |

### 操作日志表 (operation_logs)

| 字段 | 类型 | 说明 |
|-----|-----|-----|
| id | Integer | 主键 |
| user_id | Integer | 操作人ID |
| operation | String | 操作类型 |
| target | String | 操作对象 |
| detail | Text | 详情JSON |
| created_at | DateTime | 操作时间 |

## 安全设计

### 认证流程

1. 用户登录 → 验证密码 → 创建Session → 返回Cookie
2. 后续请求 → 验证Session → 允许访问
3. Session过期 → 跳转登录页

### API安全

- Session-based认证
- CSRF保护
- 请求参数验证
- 操作日志审计
