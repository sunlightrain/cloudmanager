# VMware vCenter 集成需求文档

## 1. 概述与目标

本文档定义 VMware vCenter 集成模块的功能需求，基于 vSphere API/SDK（pyVmomi）实现全量对接。所有操作必须满足以下约束：
- **异步化**：所有长耗时操作必须异步执行
- **任务化**：操作状态通过任务系统跟踪
- **可回滚**：关键操作支持回滚机制

## 2. 功能范围

### 2.1 数据中心 / 集群 / 主机 可视化管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 层级同步 | 自动同步 vCenter 层级结构：数据中心→集群→ESXi 主机→存储→网络 | P0 |
| 主机详情 | 展示 ESXi 主机硬件信息：CPU/内存/存储使用率、硬件状态、运行时状态 | P0 |
| 集群概览 | 集群资源概览：总资源、已分配资源、剩余资源、HA/DRS 状态 | P0 |

**数据同步策略**：
- 首次同步全量拉取
- 运行时增量同步（事件驱动 + 定时轮询）
- 支持手动触发全量刷新

### 2.2 虚拟机（VM）全生命周期管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 创建 VM | 支持自定义配置（CPU、内存、磁盘、网卡、操作系统）、从模板部署、批量创建 | P0 |
| 电源操作 | 开机/关机/重启/强制关机/挂起/恢复/销毁 | P0 |
| 资源变更 | 在线/离线调整 CPU、内存、磁盘容量 | P0 |
| 镜像/模板管理 | 虚拟机转模板、模板克隆、模板版本管理 | P1 |
| 状态监控 | 实时同步 VM 运行状态、VMware Tools 状态、IP 地址、登录账户 | P0 |

**约束**：
- 批量创建单次最多 10 台
- 资源变更需记录变更历史
- 删除操作需二次确认

### 2.3 存储管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 存储同步 | 对接 vCenter 存储：VMFS、NFS、vSAN、iSCSI | P0 |
| 存储展示 | 容量、使用率、挂载主机、关联虚拟机 | P0 |
| 存储操作 | 存储扩容、磁盘挂载/卸载、存储迁移 | P1 |

### 2.4 网络管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 交换机管理 | vSphere 标准交换机（vSS）、分布式交换机（vDS） | P1 |
| 端口组管理 | 创建/删除/配置端口组、VLAN 划分 | P1 |
| 网卡管理 | 虚拟机网卡绑定/解绑、IP 配置 | P0 |
| 流量监控 | 网络流量监控、带宽使用率 | P2 |

### 2.5 高级 VMware 特性

| 功能 | 描述 | 优先级 |
|------|------|--------|
| vMotion | 在线迁移（跨主机/跨集群） | P1 |
| Storage vMotion | 存储在线迁移 | P1 |
| 快照管理 | 创建/删除/回滚/批量清理快照 | P0 |
| HA/DRS | 高可用、分布式资源调度策略配置与查看 | P1 |
| 容错（FT） | 虚拟机容错 | P2 |
| 资源池 | 资源池管理 | P2 |

**快照约束**：
- 禁止长期快照（超过 72 小时自动告警）
- 快照链深度最多 3 层

## 3. 用户交互流程

### 3.1 vCenter 连接配置
```
用户输入 vCenter 信息 → 连接测试 → 保存配置 → 触发首次同步
```

### 3.2 虚拟机创建
```
填写 VM 配置 → 参数校验 → 创建任务 → 异步执行 → 任务状态轮询 → 完成通知
```

### 3.3 资源变更
```
选择 VM → 选择变更类型 → 填写新值 → 预检（quota/资源） → 确认执行 → 异步变更 → 结果反馈
```

## 4. 错误处理与回滚

| 场景 | 处理策略 |
|------|----------|
| vCenter 连接中断 | 自动重连（3 次重试），任务标记为失败 |
| 操作超时 | 任务超时后进入未知状态，提供手动恢复选项 |
| 快照回滚失败 | 保留原快照，记录失败原因，告警通知 |
| 存储迁移失败 | 自动回滚到原存储，任务标记失败 |

## 5. 非功能需求

| 指标 | 要求 |
|------|------|
| 同步延迟 | 状态变更到 UI 展示 < 5 秒 |
| API 超时 | 长操作设置 5 分钟超时 |
| 并发限制 | 单用户最多 5 个并行任务 |
| 离线支持 | 网络中断时提供只读缓存 |

## 6. 依赖关系

- 依赖 pyVmomi 7.0+
- 依赖 vCenter 6.7+
- 依赖 Python 3.10+
