## 1. 引言

### 1.1 目的

本文档定义 VMware Cloud Manager 项目中 vSphere 核心能力对接的功能需求和非功能需求，作为技术设计和开发验证的依据。

### 1.2 范围

本文档涵盖以下 vSphere 核心能力模块：

- 数据中心 / 集群 / 主机可视化管理
- 虚拟机全生命周期管理
- 存储管理
- 网络管理
- 高级 VMware 特性对接

### 1.3 定义与缩略语

| 术语 | 定义 |
|------|------|
| vCenter | VMware vCenter Server，vSphere 虚拟化平台管理核心 |
| ESXi | VMware 虚拟化主机操作系统 |
| pyVmomi | VMware 官方 Python SDK，用于 vSphere API 调用 |
| vMotion | VMware 在线虚拟机迁移技术 |
| Storage vMotion | VMware 在线存储迁移技术 |
| DRS | Distributed Resource Scheduler，分布式资源调度 |
| HA | High Availability，高可用性 |
| VMFS | Virtual Machine File System，VMware 虚拟机文件系统 |
| vDS | vSphere Distributed Switch，分布式交换机 |
| vSS | vSphere Standard Switch，标准交换机 |

## 2. 功能需求

### 2.1 数据中心 / 集群 / 主机可视化管理

#### FR-001: vCenter 层级结构同步

| 属性 | 值 |
|------|-----|
| 需求ID | FR-001 |
| 需求类型 | 能力建设 |
| 优先级 | P0 |

**EARS 格式：**

```
WHEN 用户请求同步 vCenter 层级结构
THEN 系统 SHALL 自动同步并展示 vCenter 下的完整层级结构
     包括：数据中心 → 集群 → ESXi 主机 → 存储 → 网络
     并在层级结构变化时自动更新
```

**验收标准：**
- [ ] 支持展示数据中心列表，每个数据中心下展示其包含的集群
- [ ] 支持展示集群列表，每个集群下展示其包含的 ESXi 主机
- [ ] 支持展示 ESXi 主机列表，每台主机下展示其关联的存储和网络
- [ ] 支持树形层级展示，层级深度为 5 级
- [ ] 支持手动刷新和自动定时同步（可配置同步间隔，默认 60 秒）

#### FR-002: ESXi 主机硬件信息展示

| 属性 | 值 |
|------|-----|
| 需求ID | FR-002 |
| 需求类型 | 能力建设 |
| 优先级 | P0 |

**EARS 格式：**

```
WHEN 用户查看 ESXi 主机详情
THEN 系统 SHALL 展示主机的硬件信息
     包括：CPU 型号 / 核心数 / 频率、内存总量 / 型号、存储总量
     运行时状态、硬件健康状态、告警信息
     并且实时更新资源使用率
```

**验收标准：**
- [ ] 展示 CPU 信息：型号、核心数、线程数、频率、虚拟化技术
- [ ] 展示内存信息：总量、已使用量、使用率、型号
- [ ] 展示存储信息：总容量、已使用量、使用率、磁盘类型
- [ ] 展示网络信息：网卡列表、IP 地址、端口速率、连接状态
- [ ] 展示运行状态：电源状态、运行时间、维护模式状态
- [ ] 展示硬件健康状态：风扇、温度、电源、内存健康
- [ ] 资源使用率支持折线图展示历史趋势（7 天/30 天）

### 2.2 虚拟机全生命周期管理

#### FR-004: 创建虚拟机

| 属性 | 值 |
|------|-----|
| 需求ID | FR-004 |
| 需求类型 | 核心功能 |
| 优先级 | P0 |

**EARS 格式：**

```
WHEN 用户请求创建虚拟机
THEN 系统 SHALL 支持以下创建方式：
     1. 自定义配置创建（CPU、内存、磁盘、网卡、操作系统）
     2. 从模板部署
     3. 批量创建（指定数量和命名规则）
     AND 系统 SHALL 在创建过程中显示任务进度
     AND 系统 SHALL 在创建失败时回滚已分配的资源
```

**验收标准：**
- [ ] 支持自定义 CPU 数量（1-64 核）、CPU 规格（qemu64、qemu64-vmx等）
- [ ] 支持自定义内存大小（512MB-64TB）
- [ ] 支持添加多个虚拟磁盘，指定磁盘大小、存储策略、厚/精简置备
- [ ] 支持添加多个虚拟网卡，指定网络类型（E1000、VMXNET3）、MAC 地址模式
- [ ] 支持选择操作系统：Windows 系列、Linux 系列（含主流发行版）
- [ ] 支持从模板部署，自动继承模板配置并允许自定义修改
- [ ] 支持批量创建，指定数量（1-100）和命名规则（如 vm-{seq:3}）
- [ ] 创建过程支持任务进度展示（百分比、当前步骤、预计剩余时间）
- [ ] 创建失败时自动回滚已分配的存储、网络等资源

#### FR-005: 虚拟机电源操作

| 属性 | 值 |
|------|-----|
| 需求ID | FR-005 |
| 需求类型 | 核心功能 |
| 优先级 | P0 |

**EARS 格式：**

```
WHEN 用户请求对虚拟机执行电源操作
THEN 系统 SHALL 支持以下操作：开机、关机、重启、强制关机、挂起、恢复、销毁
     AND 系统 SHALL 在执行危险操作（强制关机、销毁）前要求二次确认
     AND 系统 SHALL 记录操作日志并支持审计
```

**验收标准：**
- [ ] 支持开机：正常启动虚拟机
- [ ] 支持关机：优雅关闭虚拟机（VMware Tools）
- [ ] 支持重启：优雅重启虚拟机
- [ ] 支持强制关机：不等待 VMware Tools，直接断电
- [ ] 支持挂起：将虚拟机置于挂起状态
- [ ] 支持恢复：恢复挂起状态的虚拟机
- [ ] 支持销毁：删除虚拟机及其所有关联资源（需二次确认）
- [ ] 危险操作前显示警告信息并要求输入虚拟机名称确认
- [ ] 所有操作记录到审计日志，包含操作人、时间、操作类型、目标对象、操作结果

#### FR-006: 虚拟机资源变更

| 属性 | 值 |
|------|-----|
| 需求ID | FR-006 |
| 需求类型 | 核心功能 |
| 优先级 | P0 |

**EARS 格式：**

```
WHEN 用户请求变更虚拟机资源配置
THEN 系统 SHALL 支持在线调整 CPU、内存、磁盘容量
     AND 这些调整 SHALL 在不中断虚拟机业务的情况下完成
     AND 系统 SHALL 记录配置变更历史
```

**验收标准：**
- [ ] 支持在线增加/减少 CPU 数量（需虚拟机支持热添加）
- [ ] 支持在线增加/减少内存大小（需虚拟机支持热添加）
- [ ] 支持在线扩展磁盘容量（不支持缩减）
- [ ] 支持离线调整所有资源（当虚拟机不支持热添加时）
- [ ] 配置变更记录到数据库，支持历史配置查询
- [ ] 支持查看配置变更日志，包含变更时间、变更前后的值、操作人

### 2.5 高级 VMware 特性对接

#### FR-014: vMotion 在线迁移

| 属性 | 值 |
|------|-----|
| 需求ID | FR-014 |
| 需求类型 | 能力建设 |
| 优先级 | P1 |

**EARS 格式：**

```
WHEN 用户请求 vMotion 迁移
THEN 系统 SHALL 支持跨主机和跨集群的虚拟机在线迁移
     AND 迁移过程中 SHALL 保持虚拟机业务连续性
     AND 系统 SHALL 展示迁移任务进度
```

**验收标准：**
- [ ] 支持跨主机迁移：同一集群内不同 ESXi 主机之间迁移
- [ ] 支持跨集群迁移：不同集群之间迁移（需共享存储）
- [ ] 支持跨数据中心迁移（需网络互通）
- [ ] 迁移过程中虚拟机业务不中断
- [ ] 支持迁移前预检查：CPU 兼容性、内存资源、网络配置
- [ ] 展示迁移任务进度：准备阶段、迁移阶段、切换阶段
- [ ] 迁移失败时自动回滚或提供手动恢复选项

**验收标准：**

#### FR-016: 快照管理

| 属性 | 值 |
|------|-----|
| 需求ID | FR-016 |
| 需求类型 | 能力建设 |

- [ ] 超过 72 小时的快照创建时返回警告并阻止
- [ ] 支持快照过期提醒：提前 24 小时通知用户清理

## 4. 异步任务需求

### 4.1 任务管理通用要求

| 需求ID | 需求描述 | 验收标准 |
|--------|----------|----------|
| TR-001 | 任务队列 | 所有长时操作必须进入任务队列异步执行 |
| TR-002 | 任务状态 | 支持任务状态查询：待执行、执行中、已完成、失败、已取消 |
| TR-003 | 任务进度 | 支持任务进度展示：百分比、当前步骤 |
| TR-004 | 任务取消 | 支持取消正在执行的任务（如果操作支持） |
| TR-005 | 任务历史 | 保留任务执行历史，记录执行结果和耗时 |
| TR-006 | 任务回滚 | 任务失败时自动回滚或提供手动回滚接口 |

### 4.2 任务优先级

| 优先级 | 说明 | 适用场景 |
|--------|------|----------|
| P0-Critical | 最高优先级 | 故障恢复、紧急停止 |
| P1-High | 高优先级 | 虚拟机创建、电源操作 |
| P2-Normal | 普通优先级 | 资源变更、快照管理 |
| P3-Low | 低优先级 | 模板创建、清理任务 |

### 4.3 回滚机制

| 需求ID | 需求描述 | 验收标准 |
|--------|----------|----------|
| TR-007 | 自动回滚 | 操作失败时自动回滚到操作前状态 |
| TR-008 | 手动回滚 | 提供手动回滚接口，支持指定回滚点 |
| TR-009 | 回滚日志 | 记录回滚操作的详细日志 |
| TR-010 | 回滚确认 | 危险操作回滚前需二次确认 |
